## 2026-10-09 批量写入落地（对齐 C# `EntityExtension` / 数据库批能力；用户："分库分表是否也能实现数据累积到一起再执行…非分库分表是否也有…性能提升空间"）

- **C# 语义实证**：`EntityExtension.Insert(list)`＝`Valid(Insert)` 逐行（雪花生成）→ 无分片或显式会话→`BatchInsert`；有分片→**按（连接,物理表）分组**→分组 BatchInsert；`BatchInsert` 按 `BatchSize`（`DAL.GetBatchSize()` 默认 5000；连接设置/全局可配）分块 → `dal.Session.Insert(table, columns, list)`（各库覆写：SQLite/MySQL/PG/SqlServer/DuckDB 多行 VALUES / Oracle 参数数组）。`Delete(list)`：单主键且>1 → 1000/批 `pk IN (...)`。`EntityQueue.OnProcess` → `batch.Insert/batch.Delete`。**useTransition 默认关**（C# 注释：SQLite 默认事务大范围锁行，由外部控制）。`BuildInsertColumns`：**首行**自增列为 0→排除自增列（含非零→包含）。
